Resumo

Antes de corrigir um defeito, alguém precisa descobrir onde ele está. Os resultados publicados com LLMs são animadores, mas quase todos vêm de projetos Java e Python bem testados.

Minha pesquisa mede o que acontece em C#, comparando código com testes automatizados e código legado, sem testes. A execução piloto está publicada inteira: scripts, consultas, respostas e métricas.
